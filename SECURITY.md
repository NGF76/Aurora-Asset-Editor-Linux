Security Policy

Supported Versions

Version	Supported
1.0.x	:white_check_mark:
< 1.0	:x:
Reporting a Vulnerability

If you discover a security issue in this project, please report it by opening a private security advisory through GitHub:

Go to the Security tab of this repository.

Click Report a vulnerability.

Provide a clear description of the issue.

Alternatively, you can contact me through the email listed on my GitHub profile.

Response Time
This project is maintained by a student in their free time. I will review reports when I can, which may take several days or longer. Please be patient. If the issue is valid and I have time to fix it, I will do my best to address it and credit you for the discovery.


Scope

This policy applies to the source code and official release packages distributed through this repository.

Thank you for helping keep this project safe.
